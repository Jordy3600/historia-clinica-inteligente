# HistorIA Clínica Perú

Quiero una app médica llamada HistorIA para clínicas pequeñas en Perú. Los doctores inician sesión con usuario y contraseña. En la pantalla principal, ingresan el nombre o código del paciente y pegan el historial clínico en texto libre. Al presionar "Generar resumen", la app organiza el texto automáticamente en cinco secciones: 1) Motivo de consulta, 2) Antecedentes médicos, 3) Diagnóstico o impresión clínica, 4) Alertas y alergias, 5) Recomendación de tratamiento. Debe existir un botón para descargar o imprimir el resumen en PDF. También necesito una pantalla de "Historial de pacientes" que liste todos los resúmenes generados, con nombre del paciente y fecha, y que al hacer clic se pueda volver a ver el resumen completo. Todos los datos deben guardarse en una base de datos real (no en el navegador), con conexión segura HTTPS. Diseño: tema oscuro, tipografía limpia y profesional, pensado para uso médico.
